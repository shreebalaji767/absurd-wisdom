# Security Policy

## The Human Wisdom Archive

This document describes the security considerations and reporting process for The Human Wisdom Archive.

## Supported Versions

The project is a static website generated by `generate.py`.

Security fixes are generally applied to the current version of the project.

| Version | Supported |
| ------- | --------- |
| Current | Yes |
| Older versions | No |

Because the project is statically generated, users should regenerate and redeploy the site after applying security-related changes.

## Security Architecture

The project intentionally has a very small attack surface.

The normal architecture is:
